# Published data lives in a separate repo from the code

Crawling Shoham for personal use and republishing a whole Catalog publicly are different matters. Catalogs and Requirements Files are published in a separate data repo; the MIT-licensed code repo contains no crawled data. The app reads data through a configurable index URL, fetched only on explicit click. If BIU ever objects to a published dataset, only the data repo is affected, and anyone can host their own index.
